# Personal skill versions

One file per skill of the kit, e.g. `econ-industry-scan.md`, `econ-cover-letter.md`. The kit's
skills are generic (shared on GitHub); each reads its file here first and follows your rules.

Ask Claude "build my personal skills" (生成我的个人版 skill) to draft them from your knowledge base,
and "以后…" / "from now on…" in any chat to add a rule. Start from `_template.md`.
