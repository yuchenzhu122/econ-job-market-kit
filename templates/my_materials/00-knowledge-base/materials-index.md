# Materials index

Where each master file lives, and where its uploadable copy goes. Scripts read only this table, so
organize My Materials however you like and ask Claude to "update the materials index" (更新材料索引)
after moving things.

- Source: relative to My Materials, or an absolute / ~ path (e.g. your website repo). Symlinks and Finder aliases work.
- Target folder: inside the academic folder (e.g. 01_CV), or "industry:<folder>"; empty = not copied.
- Key names used by the scripts: resume (main.tex of the master resume), cv, jmp.
